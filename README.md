# My PDF

선생님을 위한 PDF 작업실입니다. 초록 계열의 한국어 화면에서 PDF를 모으고 편집하고, 수업 중 슬라이드에 필기할 수 있습니다. 파일 처리는 브라우저 메모리에서 진행하며 PDF를 서버에 업로드하지 않습니다.

## 실행

Node.js 22.13 이상 또는 24 이상이 필요합니다. 이 환경에서는 Node.js 24를 사용합니다.

```bash
cd /workspace/teacher-pdf-tool
npm ci --cache /tmp/teacher-pdf-npm-cache
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

설치 후 PDF.js의 CMap, 표준 글꼴, 이미지 디코딩 자산을 `public/pdf-assets/`에 복사합니다. 외부 CDN 없이 제공합니다. 개발 서버는 루트 경로(`/`), 프로덕션 빌드는 GitHub Pages의 `/teacher-pdf-tool/` 경로를 사용합니다.

```bash
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

`dist/`를 정적 웹 호스팅에 배포할 수 있습니다. HTTPS 환경에서는 클립보드 복사를 사용할 수 있습니다. 클립보드 권한이 없는 경우 텍스트 선택 창이 열립니다.

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다. 이후 `main`에 푸시할 때마다 `.github/workflows/pages.yml`이 의존성 설치, 테스트, 빌드를 거쳐 `dist/`를 GitHub Pages에 배포합니다. Actions의 **Deploy to GitHub Pages → Run workflow**로 수동 배포할 수도 있습니다.

배포 주소는 `https://imuzikr.github.io/teacher-pdf-tool/`입니다. 주소는 Pages 배포가 성공한 뒤 사용할 수 있습니다. 사이트는 공개되지만 사용자가 연 PDF는 서버로 전송하지 않습니다.

로컬에서 배포 빌드를 확인하려면 `npm run preview -- --port 4174 --strictPort`를 실행하고 `/teacher-pdf-tool/` 경로를 사용합니다. 다른 저장소 이름이나 사용자 지정 도메인으로 옮기는 경우 `vite.config.js`의 빌드 `base`를 수정해야 합니다.

## 기능

- PDF 파일 추가·병합: 여러 파일 선택 또는 드래그앤드롭, 파일당 최대 100MB.
- 페이지 편집: 썸네일 선택, Ctrl/⌘ 다중 선택, Shift 범위 선택, 회전, 삭제, 드래그로 순서 변경.
- 실행 취소·다시 실행: 최근 20개 편집 단계, Ctrl/⌘+Z 및 Ctrl/⌘+Shift+Z.
- 페이지 추출·병합: 왼쪽 작업 버튼으로 새 문서 조립 화면을 엽니다. 파일마다 페이지를 가로 행으로 표시하고 파일 행은 세로로 배치합니다. 선택한 페이지를 아래 새 문서 자리표시 영역에 드래그하거나 파일별·전체 선택 추가 버튼으로 넣습니다. 새 문서에서 드래그·이동 버튼으로 순서를 바꾸고 개별 제거한 뒤 **새 문서 PDF 저장**으로 하나의 파일을 만듭니다. 원본 목록은 유지되며 같은 페이지도 반복 추가할 수 있습니다. 새 문서는 화면 전환 중 유지되지만 새로 시작하거나 브라우저를 닫으면 사라집니다.
- 텍스트 복사: 선택한 페이지의 기존 텍스트를 복사합니다. 가린 페이지의 복사는 차단됩니다.
- 서명: 직접 그리거나 PNG/JPG를 추가한 뒤 문서에 클릭해서 배치합니다.
- 개인정보 가리기: 흰색 사각형을 드래그해 추가합니다. 2열 설정의 왼쪽에서 선택한 페이지(현재 한 페이지 수작업), 여러 페이지(각 페이지를 넘기며 개별 수작업), 반복 페이지(같은 위치 자동 적용)를 고릅니다. 선택한 페이지·여러 페이지에서는 전체 문서를 자유롭게 이동해 현재 페이지에 수작업합니다. 반복 페이지에서만 목록에서 선택한 페이지 또는 전체 페이지를 적용 대상으로 고릅니다. 수작업 영역은 다른 페이지에 자동 복사되지 않습니다. 여러 PDF를 추가한 경우에도 선택 또는 전체 범위에 적용할 수 있습니다. 크기가 다른 페이지는 같은 비율의 위치에 적용하므로 같은 서식의 페이지만 선택하고 저장 전 위치를 확인하세요. 일괄 적용도 한 번의 실행 취소로 되돌릴 수 있습니다. 가림 영역이 하나라도 있으면 **문서 전체를 새 이미지 PDF로 저장**하며 원래 텍스트를 포함하지 않습니다. 원본 파일은 수정하지 않습니다.
- 브라우저 OCR: 개인정보 가리기에서 영역 지정(기본값)과 단어 검색을 각각 또는 함께 선택합니다. 오른쪽 OCR 관리에서는 영역 관리와 독립적으로 현재·선택·전체 검색 범위를 설정합니다. 한국어·영어 글자를 인식해 입력한 단어를 찾고, 초록색 위치 미리보기에서 결과를 선택한 뒤 흰색으로 가립니다. 쉼표·줄바꿈으로 최대 100개 단어를 입력할 수 있습니다. OCR과 영역 지정을 함께 켜면 OCR 적용 후 수동 지정이 이어집니다.
- 용량 줄이기: 200/150/110dpi 및 JPEG 품질 선택으로 이미지 PDF를 다운로드합니다. 원본에 따라 결과 파일이 더 커질 수 있습니다.
- 슬라이드·프레젠테이션: 전체 화면을 지원하는 브라우저에서는 전체 화면으로 전환합니다. 좌우 방향키로 페이지를 넘기고, 레이저 포인터는 버튼 또는 L로 전환합니다. 포인터는 PDF에 저장되지 않습니다. 프레젠테이션의 **슬라이드 재생으로 돌아가기**는 작업을 유지하며 필기 화면으로 돌아갑니다. **종료**는 슬라이드 작업을 끝내고 변경 사항의 저장 여부를 묻습니다. 펜 색상은 검정·붉은색·파란색·보라색·주황색·노란색·흰색·초록색 팔레트이며 형광펜은 노랑·연두·분홍·하늘색·주황·보라 팔레트를 사용합니다. 도구마다 선택한 색상을 유지합니다. 슬라이드의 확대·축소·맞춤은 캔버스 하단 중앙의 반투명 컨트롤에 있습니다. 마우스를 하단 근처로 움직이거나 키보드로 컨트롤에 포커스하면 나타나며 터치 화면에서는 항상 표시합니다. 슬라이드에서는 펜, 형광펜, 도형, 텍스트, 편집 요소 이동, 지우개, 확대 및 화면 이동을 지원합니다.
- 도형: 직선, 원, 삼각형, 사각형, 오각형, 육각형, 2차원 좌표축, 3차원 좌표축 그림을 선택하고 드래그해서 그립니다. 도형 버튼에서 목록을 바로 열며 색상과 굵기를 조절합니다. 선택 도구로 도형의 선을 클릭해 이동하고 모서리 조절점으로 크기를 바꾸며 지우개로 제거할 수 있습니다. 2차원 좌표축에는 눈금이 없습니다. 본문에 그린 도형은 PDF에 저장됩니다. 단축키는 G입니다.
- 캡처 모드: 슬라이드에서 문서의 영역을 드래그하면 현재 필기와 가림 영역을 포함한 이미지를 화면 위에 고정합니다. 페이지를 넘겨도 유지되며 캡처 제목줄을 드래그하거나 방향키로 이동하고 왼쪽 위 ± 버튼 또는 테두리·모서리 드래그로 비율을 유지하며 크기를 조절합니다. 슬라이드의 펜·형광펜·도형·지우개를 캡처 위에서도 사용할 수 있고 레이저 포인터로 가리킬 수 있습니다. 캡처 위 필기는 캡처와 함께 임시로 유지되며 PDF 본문에 저장되지 않습니다. 여러 캡처를 띄울 수 있으며 캡처 창은 PDF에 저장되지 않고 슬라이드 종료 시 닫힙니다.
- 빈 페이지 추가: 현재 페이지 바로 다음에 같은 크기·방향의 흰색 연습 페이지를 삽입하고 펜 도구로 전환합니다. 이전 페이지는 왼쪽 참고 화면, 새 연습 페이지는 오른쪽 필기 화면으로 나란히 표시합니다. 참고 화면에서도 캡처할 수 있으며 이동 도구로 왼쪽이나 오른쪽 페이지를 드래그하면 두 페이지 화면을 함께 이동합니다. 해당 연습 페이지로 다시 이동하면 슬라이드 작업 중 두 쪽 보기가 유지됩니다. 슬라이드에서 페이지나 필기를 변경한 뒤 종료하면 저장하고 종료, 저장하지 않고 종료, 취소를 선택합니다. 저장은 원본과 연습 페이지·필기를 포함한 새 `_수업.pdf`를 다운로드합니다. 저장하지 않으면 슬라이드 시작 전 페이지·편집 상태를 복원합니다. 다운로드가 실패하면 작업과 선택 창을 유지합니다. 브라우저의 전체 화면 종료에도 같은 저장 선택이 표시됩니다.

## 브라우저 OCR

OCR 엔진과 한국어·영어 모델은 `npm ci`의 postinstall에서 `public/ocr-assets/`로 복사되어 사이트와 함께 배포됩니다. 엔진은 단어 검색을 처음 실행할 때 불러오며 외부 OCR API를 호출하지 않습니다. 브라우저는 인식 모델만 캐시하고 PDF와 OCR 결과를 서버에 전송하거나 영구 저장하지 않습니다.

모델 다운로드와 인식에는 기기 성능에 따라 시간이 걸립니다. 페이지는 한 장씩 처리하며 도중에 취소할 수 있습니다. 인식 오류나 누락이 있으므로 가려질 위치와 전체 문서를 확인한 뒤 공유하세요. 흐린 스캔, 작은 글씨, 손글씨, 복잡한 표에서는 정확도가 낮아질 수 있습니다. 문자 좌표가 없는 인식 결과에서는 해당 단어 전체를 넓게 가릴 수 있습니다. OCR은 입력한 단어를 찾는 기능이며 개인정보를 자동으로 분류하지 않습니다.

실제 한국어·영어 스캔 인식 테스트에는 Noto CJK 글꼴이 필요합니다. Ubuntu에서는 `fonts-noto-cjk` 패키지를 사용하며 GitHub Actions에서 자동 설치합니다.

## 저장 방식과 한계

편집하지 않은 페이지는 원본 PDF 페이지를 복사해 텍스트를 유지합니다. 필기·텍스트·서명을 추가한 페이지는 이미지로 저장되므로 해당 페이지의 검색·복사는 사용할 수 없습니다. 개인정보 가리기나 용량 줄이기를 사용하면 문서 전체가 이미지 PDF가 됩니다. 이미지 저장 시 기본 150dpi, 최대 변 길이 8192픽셀을 적용합니다. 확대 시 원본 벡터 PDF보다 선명도가 낮을 수 있습니다.

암호 PDF 열기, 원본 PDF 텍스트 직접 수정, 자동 개인정보 탐지, 클라우드 저장은 지원하지 않습니다. 지우개와 선택 도구는 이 앱에서 추가한 편집 요소에 적용됩니다. 새로고침이나 브라우저 종료 시 편집 내용은 사라지므로 PDF를 내려받아 보관하세요.

큰 문서는 브라우저 메모리와 기기 성능에 따라 처리 시간이 길어질 수 있습니다. 썸네일은 화면 근처에 있는 페이지만 렌더링하며 이미지 저장은 한 페이지씩 처리합니다.

## 검증

PDF 처리 테스트는 실제 PDF를 생성·편집·내보낸 다음 다시 열어 검사합니다. 병합과 순서 변경, 삭제, 회전, 텍스트 보존, 가림 후 전체 문서 텍스트 제거와 흰색 영역 픽셀과 선택·전체 페이지 일괄 가림, 압축 결과, 펜·형광펜·텍스트·서명 저장, 테스트용 PDF와 잘못된 입력, 빈 페이지의 크기·필기 저장, 회전된 페이지의 영역 캡처를 검증합니다.

총 18개 테스트에는 JSDOM과 실제 PDF 렌더러를 사용하는 React 조작 테스트도 포함됩니다. 파일 추가 → 선택 → 회전 → 삭제/복원 → 복사 → 가리기 → 다운로드, 슬라이드 필기 저장, 캡처 유지·이동·경계 크기 조절·필기·지우개·레이저, 빈 페이지 삽입과 두 쪽 보기, 저장·취소·복원과 다운로드 실패 후 재시도까지 실행합니다. 실제 OCR 테스트는 텍스트가 없는 이미지 PDF에서 한국어 학교명과 영어 문구를 인식하고, 흰색으로 가린 결과를 다시 열어 검사합니다. 취소와 한글 단어 연결·중복 매칭도 검증합니다. 이 테스트는 실제 브라우저에서의 화면·입력 검증을 대체하지 않습니다.

사용자 요청에 따라 첨부 화면과의 시각적 비교는 생략했습니다. 이 세션에서는 브라우저 UI 조작 검증을 수행하지 않았습니다.
